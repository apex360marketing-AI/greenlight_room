# Greenlight Room

Campaign review deck for Northern Peptides (Grace Taylor), built by Apex 360 AI.

A single self-contained HTML page — 19 sections, all images inlined, no build step
and no external dependencies beyond a Google Fonts stylesheet (which it degrades
from cleanly). Open `index.html` in any browser, or serve the repo as a static site.

## What's in it

- Brand routes, a sixty-day campaign calendar, compliance and market research
- Two live models: the Google budget and the revenue model, both recalculating in-browser
- A cost-evidence page pricing the engagement two independent ways, every rate cited
- Print / Save as PDF from the menu

## Verified

30 automated gates and 5 phase slices, plus 101 mutations across 11 runners —
each guard confirmed to fail when the thing it protects is removed.
